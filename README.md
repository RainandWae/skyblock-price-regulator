# SkyBlock Price Regulator

A Hypixel SkyBlock market tracker for Bazaar and Auction House prices, with price anomaly detection, flip tracking, profit alerts, and easy-to-read market charts.

## Current features

- Live Bazaar market table from Hypixel's public API
- Searchable item list
- High-spread alert signals
- Auction House BIN scanner from the first active auction page
- Manual "Bought now" tracker with target profit percent
- Local price history snapshots for charts
- Device-local saved tracked buys

## Notes

This project is not affiliated with Hypixel. It uses public Hypixel SkyBlock market endpoints and should respect Hypixel API caching and rate limits.
